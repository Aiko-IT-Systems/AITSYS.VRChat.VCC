# AITSYS VCC

The public VRChat Creator Companion package listing maintained by AITSYS.

## Add the listing

Add the following repository URL to the VRChat Creator Companion or ALCOM: `https://vcc.aitsys.dev/index.json`

Or visit the page: https://vcc.aitsys.dev

The listing currently includes:

- [`dev.aitsys.vrc-discord-rpc`](https://github.com/Aiko-IT-Systems/AITSYS.VRChat.DiscordRPC) - Discord Rich Presence for Unity projects using the VRChat SDK.

Each package is developed and released from its own source repository. This
repository only aggregates those releases and publishes the package listing.
